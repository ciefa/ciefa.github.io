A quick guide

  1. Open HTML to choose your handbook. The original file is read only.
  2. Select text, then add a comment. Tick Suggest replacement text to propose an edit.
  3. Preview suggestions opens a second view on the right. It shows accepted changes plus all pending replacement suggestions, without accepting them. The left pane shows the current document with accepted changes only. Rejected suggestions and plain comments do not change the preview’s wording.
  4. Accept replaces that passage in the current document too. Reject removes it from the preview. You can undo either decision.
  5. Save annotated copy downloads annotated-your-filename.html. Open that copy directly to continue reviewing or send it to your manager.

Add new comments in the left pane. Click a highlighted change in the preview to find its comment. Scroll together links the two views; turn it off to read them independently.

Save again after making changes. Closing or refreshing the page discards anything you have not downloaded. This tool does not overwrite files or save automatically.

Export revised HTML creates a separate document with accepted edits applied, without the comments or review controls. Previewing never adds pending suggestions to this export.

For static HTML documents. Embedded styles and images are supported. Scripts, external resources, and external links are disabled in the review. Linked files are not bundled. Replacement suggestions work within one paragraph or table cell and inherit the formatting at the start of the selection; comments can span multiple paragraphs.
